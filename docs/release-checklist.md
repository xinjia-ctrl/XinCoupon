## 后续风险

- 当前仍是单体应用，尚未拆分网关、用户、结算、优惠券等独立服务。
- 当前鉴权为请求头模拟，不等同于完整登录、签名验签或 OAuth2/JWT 体系。
- 当前 Redis 主要用于活动库存缓存，尚未扩展到热点模板缓存和多级缓存。
- 当前没有压测报告、监控大盘、链路追踪和限流熔断。
- 当前 Nacos 只用于服务注册配置，尚未接入配置中心拆分。
